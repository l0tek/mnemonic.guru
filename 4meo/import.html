    README importieren

    README auswählen, Vorschau prüfen und als Howto veröffentlichen.

    Wo landet meine README?

    Der Inhalt wird als Anleitung unter Howtos gespeichert und ist nach dem Import sofort öffentlich sichtbar. Du findest ihn anschließend unter Inhalte → Howtos bearbeiten.

    Die ursprüngliche .md-Datei bleibt auf deinem Gerät. Auf dem Server wird der formatierte Inhalt gespeichert. Jede Datei erzeugt ein neues Howto; ein erneuter Import legt einen weiteren Eintrag an.

    Speicherort & Sicherung

    Die Inhalte liegen auf dem Server in data/content.sqlite im Website-Verzeichnis, Tabelle pages, Eintrag howto. Es wird keine separate README-Datei abgelegt und die Datei howto.html wird nicht verändert. Sichere die SQLite-Datenbank und bewahre deine Originaldateien auf.

    Maximal 2 MB insgesamt. Der Titel wird aus der ersten Hauptüberschrift übernommen. Lokale Bilddateien werden nicht mit importiert.
